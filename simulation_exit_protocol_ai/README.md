# Simulation Exit Protocol AI Short

Production blueprint for a 5-minute realistic psychological thriller using a text-to-image -> image-to-video workflow.

## Files

- `docs/production_bible.md` - enhanced screenplay, character continuity, voiceover/dialogue package, and sound notes.
- `docs/character_bible.md` - detailed character descriptions and Artlist Studio-ready character prompts.
- `docs/location_bible.md` - wide establishing location prompts for Oscar's apartment, university, hallway, and Room 214.
- `docs/shot_list.csv` - 50-shot production list with duration, camera, action, audio/dialogue, and image prompt.
- `docs/prompt_pack.md` - clean text-to-image prompt pack, including global style and character locks.
- `docs/production_checklist.md` - generation, continuity, animation, audio, and acceptance checklist.

## Suggested Workflow

1. Read `docs/production_bible.md`.
2. Cast and lock characters using `docs/character_bible.md`.
3. Lock key environments using `docs/location_bible.md`.
4. Generate still frames from `docs/prompt_pack.md`.
5. Track production using `docs/shot_list.csv`.
6. Animate selected stills image-to-video.
7. Record voiceover/dialogue from the production bible.
8. Validate the edit with `docs/production_checklist.md`.

The shot durations total 278 seconds as a base timeline; with dialogue breathing room, transitions, and the final pullback, the edit should land near 5 minutes.
